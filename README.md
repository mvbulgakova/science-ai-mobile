# 🧠 Science AI Mobile
Локальный ИИ-ассистент для Android (Termux).

## Возможности
- 📝 Qwen 2.5 7B: Тексты, стиль, русский язык.
- 🧮 DeepSeek Math 7B: Интегралы, формулы, LaTeX.
- 🔄 Умный маршрутизатор: Сам выбирает модель.

## Быстрый старт
1. Установи Termux и Termux:API из F-Droid.
2. Запусти: `bash setup.sh`
3. Используй: `./ai.sh "твой вопрос"`
